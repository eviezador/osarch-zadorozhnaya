DIAGNOSIS (made before any conversion)

Encoding:    KZ-1048 (iconv name RK1048)
             - one byte per letter, not D0/D1 pairs, so it is not UTF-8:
               "Фамилия" = d4 e0 ec e8 eb e8 ff
             - the surname on line 2 starts with byte A3. In KZ-1048 A3 = "Ә",
               giving "Әбдірахманова". In Windows-1251 A3 = "Ј", which would give
               "Јбдірахманова" - wrong. So it is KZ-1048, not Windows-1251.
Line ending: CRLF - line 1 ends with 0d 0a (offset 0x24-0x25)
BOM:         no - the file starts with 49 44 ("ID"), not EF BB BF
Separator:   ;  (byte 3b)
